# Tranquil Roots

An AI-powered head spa and wellness booking platform built as a full-stack software engeneering capstone project.

## Project Overview
Tranquil Roots is a modern web application that allows users to browse wellness services, book appointments, manage their bookings, and recieve AI-powered wellness recomendations based on their scalp and wellness concerns. 

The project demonstrates full-stack software engineering using React, Node.js, Express, and MongoDB while following a professional 3-tier achitecture.

## Tech Stack

### Frontend

- React.js
- React Router
- Axios

### Backend

- Node.js
- Express.js
- JWT Authentication
- bcryptjs

### Database

- MongoDB Atlas
- Mongoose
